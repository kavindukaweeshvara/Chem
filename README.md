# Buddika Wijesundara - Advanced Level Chemistry LMS

![Version](https://img.shields.io/badge/version-1.0.0-blue)

A highly secure Learning Management System built with Node.js, Express, and PostgreSQL for Advanced Level Chemistry students.

## 🔐 Security Features

- **VdoCipher DRM Integration** - Hollywood-grade video encryption
- **Dynamic Watermarking** - Student ID & Mobile number overlay
- **AI Bot Blocking** - Blocks GPTBot, ClaudeBot, Google-Extended
- **Anti-Piracy** - Disabled downloads, right-click protection
- **Rate Limiting** - Prevents brute force attacks
- **Security Headers** - Helmet.js, CORS, CSP

## 📋 Features

### For Teacher (Admin):
- ✅ One-click student enrollment/revocation
- ✅ Search students by ID (BC-1001 format)
- ✅ Video watch analytics dashboard
- ✅ Inactive student alerts (7+ days)
- ✅ No-code admin panel

### For Students:
- ✅ Unique Student ID (BC-1001, BC-1002...)
- ✅ Profile management (NIC, School, Mobile)
- ✅ WhatsApp payment proof submission
- ✅ Clean card-based lesson UI
- ✅ Live session & recording access
